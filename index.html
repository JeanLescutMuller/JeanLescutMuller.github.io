Agentic workflows

I run many Claude Code and Codex agents in parallel, across a laptop, a home server and the cloud. To make that productive and safe, I built my own tooling around them. The open-source ones are linked.

agent-resumeopen sourceIndex, search and resume Claude Code and Codex sessions across machines; restore them all after a crash.
agent-trackeropen sourceReverse-engineers, from measurements, how Claude Code and Codex compute their usage limits.
agent-notify · agent-statuslineopen sourceNotifications across many agent panes, and one status line for Claude Code and Codex.
claude-close-keep-screen · agent-quotaopen sourceClose idle sessions to free memory; protect and spend the weekly agent quota.
agent-firewallA firewall for agents: every email and chat message an agent reads is checked for prompt injection; every personal fact in a message it sends is listed for review. A hook vets every tool call.
agent-vaultPasswords agents never see: they log in to websites through a vault that types the password for them; secrets are masked in every output.
agent-chromeAgents in the browser: each drives its own Chrome profile, headless by default, with every tab accounted for.
job-runnerScheduled agent jobs: recurring agent and data jobs across several machines, with statuses and one phone dashboard.
processing-meeting-recordingMeetings to transcripts: a recording becomes a compressed video, an MP3 and a transcript with the speakers named.
